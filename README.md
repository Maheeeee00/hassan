### Quick API examples

- Health:
  - `GET <WEB_APP_URL>?action=health`
- Read curriculum:
  - `GET <WEB_APP_URL>?action=curriculum`
- Update calander:
  - `POST <WEB_APP_URL>?sheet=Curriculum_Update_Calander`
- Update sallybus:
  - `POST <WEB_APP_URL>?sheet=Curriculum_Update_Sallybus`
